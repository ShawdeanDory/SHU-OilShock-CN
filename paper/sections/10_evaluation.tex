\section{模型评价与推广}

\subsection{模型优点}

\begin{enumerate}
  \item \textbf{预测与归因分离。}月度滚动预测回答可预测性，日度CAR和安慰剂回答
  事件附近的异常性，递归VAR回答冲击来源，避免把一次大预测误差直接命名为战争贡献。

  \item \textbf{跨问接口一致。}Q1的结构冲击、Q2的动态响应和Q3的官方价格层反事实
  按明确接口进入Q4；价格风险、宏观压力和政策缓冲不被错误相加为单一因果数字。

  \item \textbf{简单基线可独立完成任务。}no-change、ARDL、分国传导率与高斯随机游走
  均能产生完整输出。高级模型未胜出时如实保留负结果，提高结论可信度。

  \item \textbf{政策优化显式呈现代价。}SAPR同时控制平均损失、尾部损失、延期负担和
  调价波动，用Pareto前沿而非主观加权总分选解；训练与检验隔离，避免使用2026冲击
  反向调参。

  \item \textbf{可复现与可审计。}数据截止日、发布滞后、随机种子、原始来源、代码与
  结果哈希均被固定，工业增加值结构性缺失未被插值，论文数值可逐项追溯。
\end{enumerate}

\subsection{模型局限}

\begin{enumerate}
  \item \textbf{单次事件仍有同期混杂。}CAR的安慰剂显著性说明事件窗口异常，但无法
  完全剥离同期供需、金融和其他政治消息。未来可引入受影响程度不同的期货合约、航线或
  高频工具变量，加强事件因果识别。

  \item \textbf{结构冲击依赖递归排序。}SVAR的经济含义依赖当期零约束，且历史月度
  冲击不是对本次战争的唯一标签。可用符号约束或高频油供给新闻工具进行交叉验证。

  \item \textbf{宏观样本和统计功效有限。}IAV存在官方1--2月合并发布，GDP只有季度
  频率，局部投影在远期的区间较宽。结论因此只能写成未发现稳健总体增长损失，而不能把
  ``不显著''解释成``没有影响''。

  \item \textbf{跨国价格口径不能完全一致。}中国使用受管制标准品上限，欧洲使用含税
  零售价，日本和韩国使用全国普通汽油价；固定效应和收益率转换可减轻但不能消除税制、
  品质与地区构成差异。中国历史调价表来自东方财富公开数据中心镜像，虽经日期与幅度
  规则校验，仍不等同于官方原始数据库；2026年临时调控缺口则以国家发展改革委及北京
  市发展改革委公告逐项核验。两类来源的权威性与结构化程度不同，是政策反事实的重要
  数据限制。

  \item \textbf{政策存在内生性与一般均衡缺口。}临时调控恰在冲击最强时推出，局部
  反事实固定其他环境，也未完整计量炼油企业、财政、库存和居民异质性福利。累计未调价
  差额只是成本代理。

  \item \textbf{风险模型具有样本外尾部局限。}FHS只能重采样历史标准化残差，不能产生
  历史从未出现的制度断裂；GJR持久性较高，长期区间对模型设定敏感。SAPR的最优性仅在
  三状态、六个月、离散传导率规则族内成立。
\end{enumerate}

\subsection{推广方向}

本框架可推广到天然气、粮食、关键矿产和国际运价等受地缘风险驱动的市场：先以可用
基线评价价格预测，再分离事件异常与结构冲击，继而估计进口成本到国内价格和产出的
传导，最后在政策约束下进行尾部风险和多目标缓冲决策。若获得更完整的进口单位价值、
战略储备释放、行业投入产出与财政补贴数据，可把当前局部政策情景扩展为部门异质性或
一般均衡分析；但新增模块仍应通过样本外基线和数值冻结门禁。
