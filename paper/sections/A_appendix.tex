\section{主要算法流程}

\subsection{扩展窗口预测与事件CAR}

\begin{enumerate}
  \item 对每个目标月和期限 $h\in\{1,3,6\}$，将数据截断在预测原点，分别拟合
  no-change、ARIMA、SARIMAX、ETS和Theta；保存点预测、区间和误差。
  \item 在相同目标月配对模型误差，计算MAE、RMSE、相对误差和DM--HLN检验，按
  预注册规则选择主预测。
  \item 仅用E1前日度数据拟合AR(3)+美元收益模型，递归生成前三个交易日条件期望，
  计算 $CAR[0]$、$CAR[0,+1]$、$CAR[0,+2]$。
  \item 对排除真实事件前后七日的周末重复相同步骤，构造经验安慰剂分布。
\end{enumerate}

\subsection{局部投影与政策反事实}

\begin{enumerate}
  \item 按递归排序估计历史结构VAR，得到供给、全球需求和石油特定风险冲击。
  \item 对每个宏观结果与期限估计局部投影；从同一月度样本执行移动块bootstrap，生成
  逐点区间、联合最大 $t$ 区间和FDR校正量。
  \item 对七国分别估计本币Brent到国内燃油的分布滞后传导，再估计含国家与年月固定
  效应的相对中国面板响应。
  \item 将2026年两次机制应调与实际调价差额累计加回官方价格路径，通过中国国内价格
  到PPI、CPI、IAV的动态核传播，并联合抽样参数不确定性。
\end{enumerate}

\subsection{FHS风险模拟与SAPR优化}

\begin{enumerate}
  \item 在截止日前日收益上估计GJR--GARCH，保存标准化残差；从经验残差中有放回抽样，
  递归生成1、3、6月共20000条油价路径。
  \item 用15个季度末原点对FHS与高斯随机游走进行统一回测，比较分位损失、区间覆盖率、
  区间宽度和中位数绝对误差。
  \item 仅在2013-03--2021-12开发样本计算状态阈值，枚举满足
  $\rho_N\ge\rho_S\ge\rho_E$ 的1771条规则，计算四个目标并筛选Pareto集。
  \item 在Pareto集内归一化四目标，选择距理想点最近的膝点；使用2022-01--2026-06
  隔离样本、2000次参数抽样和块bootstrap与三类基线比较。
\end{enumerate}

\section{复现顺序与环境说明}

全部数据处理和模型以随机种子20260730、截止日2026-06-30运行。建议按``数据构建与
校验---Q1---面板重建---Q2---Q3---Q4风险层---Q4 SAPR---结果冻结---最终验证''顺序
执行。冻结清单指定Python 3.11.9和精确依赖版本；在其他环境中验证时可能产生环境警告，
但论文数值必须与冻结哈希一致。完整重跑后，最终门禁应同时满足：风险探针总体状态为
通过、无阻塞探针、论文定稿许可为真，且冻结源哈希与当前结果一致。

\section{证据解释边界}

\begin{itemize}
  \item $ARBaselineGap$ 是战前AR规律的描述性差额，不是战争净因果贡献。
  \item Q2联合区间跨零时，不将点估计写成稳健总体增长损失。
  \item Q3的总体判断是部分支持；燃油传导维度本身不支持中国全面更优。
  \item Q4尾部概率是固定信息集下的条件概率；宏观压力与政策反事实不可相加。
  \item SAPR膝点只在注册的三状态、六个月、四目标规则族内最优；延期差额不是财政支出。
  \item Polymarket等Innovation Track数据仅作为后续研究储备，未进入原三问及问题四的
  正式模型、参数估计或结论证据链。
\end{itemize}
