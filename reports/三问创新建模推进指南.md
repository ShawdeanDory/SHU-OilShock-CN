## 1. 本指南的定位

本文件不是要求把方法逐项堆进论文，而是给出一个尽可能宽的研究设计空间。文中“创新”指可以形成项目特色的组合、指标、接口或反事实设计，不代表已经获得经验结果，也不保证每种组合都优于经典模型。

三个子问题最有价值的解法不是三个孤立模型，而是建立一个可传递不确定性的统一系统：

```text
事件知识图谱 + 多频油市数据 + 全球基本面
                    ↓
第一问：概率预测、状态识别、战争冲击与机制分解
                    ↓
结构冲击样本 / 反事实油价 / 风险分布 / 状态概率
                    ↓
第二问：宏观—行业—居民多层传导与动态归因
                    ↓
增长损失 / 通胀 / 行业成本 / 福利损失的联合分布
                    ↓
第三问：跨国韧性识别、政策组合归因与最优控制
                    ↓
政策数字孪生 / 政策互换 / 鲁棒策略 / 成本收益前沿
```

统一系统必须同时保留四类不同输出：

1. **Forecast**：未来油价及其概率分布。
2. **Shock identification**：战争或供需结构冲击的估计。
3. **Transmission**：冲击进入中国经济后的动态响应。
4. **Policy evaluation/optimization**：政策改变响应路径的幅度、代价与不确定性。

## 2. 三问之间的接口契约

| 接口 | 第一问输出 | 第二问输出 | 第三问使用 |

## 3. 三套可并行推进的总体架构

### 3.1 架构 A：结构因果主线

适合形成论文的可信解释主线：

```text
Narrative sign-restricted SVAR / external instrument
→ 战争冲击历史分解
→ 中国 MF-BVAR / Local Projection
→ 跨国 hierarchical panel LP
→ Synthetic Control / SDID
→ 政策移除反事实
```

特色是因果问题与预测问题严格分离，结果容易解释，适合作为论文正文骨架。

### 3.2 架构 B：多模态概率预测主线

适合追求预测精度、状态识别和风险预警：

```text
价格 + 期货曲线 + GPR/NLP + 预测市场 + 航运网络 + 宏观变量
→ TFT / TCN / XGBoost / Graph Neural Network
→ quantile forecast + adaptive conformal interval
→ regime/jump detector
→ ML forecast residual 的结构化因果归因
```

特色是多源数据、概率预测和时变不确定性。机器学习只负责预测和表征学习，战争因果结论仍交给结构识别模块。

### 3.3 架构 C：能源—经济—政策数字孪生

适合形成最强的系统性创新：

```text
油市状态空间模型
→ 中国动态投入产出 / CGE / DSGE / Agent-Based Model
→ 政策控制器
→ Model Predictive Control / robust control
→ 多目标 Pareto 前沿
```

特色是可以回答“如果政策更早、更强、更弱，或者换成他国政策会怎样”，并能够同时评价增长、通胀、财政成本、能源安全和碳排放。

三套架构可以同时存在：A 负责识别，B 负责预测和风险，C 负责机制与政策模拟。最终用相互印证而非相互替代的方式组织论文。

# 第一问：国际油价预测与战争冲击识别

## 4. 第一问应拆成的六个任务

1. 预测油价水平、收益率和波动率。
2. 判断市场处于正常、高波动、跳跃还是危机状态。
3. 构造无战争反事实价格。
4. 把战争影响分为信息/风险溢价与真实供应/运输中断。
5. 解释不同通道的相对贡献。
6. 给出未来情景分布，而非单一路径。

## 5. 第一问的数据与表征创新

### 5.1 多市场“油价状态向量”

不要只预测单一 Brent 收盘价。可以构造：

```text
S_t = [
  Brent level and return,
  WTI-Brent spread,
  Dubai-Brent spread,
  futures slope and curvature,
  realized volatility,
  implied volatility,
  jump measure,
  trading volume/open interest,
  tanker freight/insurance proxy
]
```

这使模型能够区分“价格上涨”“风险上升”“区域供应受阻”和“现货紧张”。

### 5.2 战争事件知识图谱

把战争从单一 dummy 改造成事件知识图谱：

```text
节点：军事行动、制裁、设施受损、航道事件、谈判、停火、储备释放、OPEC 决策
边：发生先后、因果候选、涉及国家、影响航线、影响品种
属性：时间、地点、可信度、意外程度、预期方向、持续性
```

由图谱派生连续指标：

- `threat_intensity`
- `physical_disruption_intensity`
- `shipping_risk_intensity`
- `sanction_intensity`
- `de_escalation_intensity`
- `event_surprise`

新闻 NLP 可用于给事件分类和测量市场注意力，但事件日期与事实必须由官方或高质量来源核验。

### 5.3 信息可得性矩阵

为所有解释变量加入：

```text
observation_date
release_date
revision_date
available_to_model_date
```

这允许进行真正的 pseudo-real-time forecasting，并能区分“历史修订数据下的好预测”和“当时信息集下的好预测”。

### 5.4 预测市场数据层：Polymarket

#### 5.4.1 为什么值得加入

Polymarket 合约价格可以作为交易者对某个明确事件的市场隐含概率。相较于一般新闻情绪，它有四个独特价值：

1. **前瞻性**：交易的是未来事件，而不是只统计已经发生的新闻；
2. **高频性**：概率会随新信息和交易连续更新；
3. **事件语义明确**：每个合约有截止日、判定规则和结算来源；
4. **可形成期限结构**：同一事件若有多个截止日期，可恢复市场对事件发生时间的分布。

当前平台存在与伊朗、霍尔木兹海峡、油气设施和 WTI 价格阈值直接相关的合约，可从 [Polymarket Iran/Oil 页面](https://polymarket.com/iran/oil)确认市场覆盖。这里的价格首先是**市场信念代理**，不是客观真实概率，更不是战争冲击的天然外生工具变量。

这一定位与预测市场研究的证据边界一致：市场可以聚合分散信息并产生有用预测，但相关性仍不能自动转化为因果解释；把二元合约价格解释为平均信念概率还依赖风险偏好和信念分布等条件，而且远期合约可能出现 favorite–longshot miscalibration。参见 [Wolfers & Zitzewitz (2004)](https://doi.org/10.1257/0895330041371321)、[Wolfers & Zitzewitz (2006)](https://doi.org/10.3386/w12200) 和 [Page & Clemen (2013)](https://doi.org/10.1111/j.1468-0297.2012.02561.x)。

#### 5.4.2 建议收集的数据

官方文档列出三类可用于研究的接口：

- [Gamma API](https://docs.polymarket.com/api-reference/predictions/overview)：市场、事件、标签、问题文本、开始/结束时间、结算规则、成交量、流动性和 `clobTokenIds`；
- [CLOB 历史价格接口](https://docs.polymarket.com/api-reference/markets/get-prices-history)：按 token id、起止时间和采样精度取得历史价格；
- [Data API 成交接口](https://docs.polymarket.com/api-reference/core/get-trades-for-a-user-or-markets)：取得市场级逐笔成交、方向、价格、数量、时间戳和交易哈希；
- [公开 WebSocket market channel](https://docs.polymarket.com/market-data/websocket/market-channel)：前瞻性采集盘口、bid/ask、价格变化和最近成交。

建议建立 `prediction_market_raw`，至少保存：

```text
event_id
market_id
condition_id
token_id
event_slug
market_slug
question
rules_text
resolution_source
market_open_time
market_end_time
observation_time_utc
outcome
best_bid
best_ask
mid_price
last_trade_price
spread
depth_near_mid
trade_size
rolling_volume
liquidity
resolved_outcome
resolution_status
retrieved_at
```

研究中优先使用 `mid_price = (best_bid + best_ask) / 2`，而不是在低流动性市场中容易陈旧的最后成交价。历史接口若只能恢复单一价格序列，应把缺失的盘口质量信息标为数据局限，不能假定历史每个时点均有相同流动性。

#### 5.4.3 从单个概率升级为“战争概率曲面”

先按机制而非关键词把合约分为：

- **物理供应**：油气设施被袭、霍尔木兹海峡关闭或通行恢复；
- **军事升级**：美伊/以伊打击、舰船护航、制裁升级；
- **缓和**：停火、谈判、航运安全承诺；
- **价格结果**：WTI/Brent 在某期限达到某个阈值；
- **政策响应**：储备释放、护航或其他明确政府行动。

对每个合约计算：

```text
pm_logit_t = log((p_t + ε) / (1 - p_t + ε))
pm_surprise_t = pm_logit_t - pm_logit_(t-1)
quality_weight_t
  = f(spread_t, depth_t, volume_t, time_to_expiry_t)
```

再构造以下四类特征：

1. **Liquidity-weighted geopolitical factor**：对多个合约的 `pm_logit` 做动态因子、PCA 或 state-space 聚合；
2. **Probability jump**：在新闻或军事事件前后测量 `pm_surprise`，作为新信息到达强度；
3. **Disagreement/liquidity stress**：spread 扩大、depth 撤出和成交集中度，用作不确定性而非事件概率；
4. **Cross-market inconsistency**：比较语义相近或逻辑嵌套合约，识别规则差异、套利约束或流动性噪声。

同一事件若存在多个截止日期，且经人工审计确认事件定义、主体、触发条件和结算来源一致，只是期限不同，令：

```text
F_k = P(T ≤ deadline_k)
```

先用 isotonic regression 施加 `F_1 ≤ F_2 ≤ ... ≤ F_K`，再计算离散风险率：

```text
h_k = (F_k - F_(k-1)) / (1 - F_(k-1))
```

由此得到“市场认为升级/停火/恢复通航最可能何时发生”的期限结构。它比单一 GPR 指数更接近第一问需要的前瞻状态变量，也能直接进入第三问的情景概率更新。若合约规则不构成严格嵌套，不得强加单调性；应作为不同事件分别建模。

#### 5.4.4 可回答的模型问题

| 用法 | 方法 | 能回答什么 | 不能回答什么 |
| --- | --- | --- | --- |
| 预测特征 | ARIMAX、MIDAS、TFT、XGBoost | 加入市场概率后是否改善油价样本外预测 | 不能证明概率变化导致油价变化 |
| 领先—滞后 | Local Projection、VAR、transfer entropy、Hawkes | 概率跳变与油价/波动谁先反应 | 共同新闻可能同时驱动二者 |
| 风险状态 | state-space、HMM、Markov-switching | 市场是否进入高升级概率/低流动性状态 | 状态标签仍是模型生成的 |
| 事件研究 | 高频窗口、price discovery decomposition | 事件信息先进入预测市场还是原油市场 | 不足以识别战争总效应 |
| 情景加权 | Bayesian scenario mixture、MPC | 用最新概率更新油价和政策情景权重 | 市场概率未经校准时会传递偏误 |

最推荐的主线是：Polymarket 负责“市场在当时相信什么”，官方事件表负责“后来确认发生了什么”，油市结构模型负责“该信息如何进入油价”。三者不能互相替代。

WTI/Brent 价格阈值合约与预测目标高度重合，应主要用作外部概率预测基线、情景分布或校准检查。若把它作为油价模型输入，必须证明所有价格都来自预测起点之前，并与相同预测期限对齐；否则容易形成同义目标泄漏，不能声称提供了独立的地缘政治信息。

#### 5.4.5 校准、泄漏与伦理边界

- 先在全部可结算的相关历史合约上做 reliability diagram、Brier score 和 log score，再决定是否对价格做 isotonic/beta calibration；
- 若规则可比且已经结算的合约数量不足，不拟合高自由度校准器；改为 raw/midquote 并列、宽区间和分层敏感性；
- 对低成交量、宽 spread、临近开盘或规则发生澄清的市场单独标记，并报告 liquidity-filter sensitivity；
- 远期二元合约可能存在 favorite–longshot bias，不能机械把 0.10 当成校准后的 10%；
- 市场创建具有选择性，“没有合约”不表示事件风险为零；
- 合约题名相似不代表结算事件相同，必须保存完整规则和结算来源。Polymarket 官方也明确说明题名只描述问题，最终以[预先定义的结算规则](https://docs.polymarket.com/concepts/resolution)为准；
- Polymarket 概率通常是战争信息到达后的中介变量。估计战争 **total effect** 时控制它会吸收一部分战争效应；它更适合预测、状态测量或显式中介分析；
- 不把 Polymarket 作为 IV：共同新闻、风险偏好、流动性和潜在知情交易都会破坏排除限制；
- 对主样本截止日执行信息冻结。2026-06-30 之后产生的合约或成交只能用于样本外情景更新，不得回填到此前的模型输入；
- 钱包地址虽公开且为 pseudonymous data，研究只做市场级或集中度统计，不尝试去匿名化，也不在无独立证据时指称某地址进行内幕交易。

## 6. 第一问的方法清单

### 6.1 统计与贝叶斯预测

| 目标 | 方法 | 可产生的新信息 |
| --- | --- | --- |
| 透明基线 | Random Walk、ARIMA、ETS | 判断复杂模型是否真正增益 |
| 外生变量预测 | ARIMAX、Distributed Lag、MIDAS | 供需、美元、GPR 的时滞贡献 |
| 系统联立 | VAR、BVAR、FAVAR | 油价与供需、金融变量的共同动态 |
| 长短期均衡 | VECM、threshold VECM | 基本面协整关系、偏离后的非线性修正 |
| 参数漂移 | TVP-VAR、Dynamic Model Averaging | 战争前后系数是否发生改变 |
| 实时多频 | Mixed-Frequency VAR、MIDAS | 日度油价、月度供需和季度宏观共同使用 |
| 潜在风险溢价 | state-space、Kalman/particle filter | 从油价、期权、航运和预测市场中滤出隐状态 |
| 预测组合 | Bayesian Model Averaging、stacking、online weighting | 不同 regime 下自动调整模型权重 |

### 6.2 波动、跳跃和状态

| 目标 | 方法 | 关键输出 |
| --- | --- | --- |
| 条件波动 | GARCH、EGARCH、GJR-GARCH、Realized GARCH | 波动率及非对称反应 |
| 长记忆波动 | FIGARCH、HAR-RV | 风险持续性 |
| 跳跃识别 | stochastic volatility with jumps、jump diffusion、bipower variation | 新闻冲击造成的离散跳跃 |
| 状态转换 | Markov-switching、Hidden Markov Model | 高低波动状态概率 |
| 结构突变 | Bai-Perron、Bayesian change point | 战争是否对应内生断点 |
| 自激升级 | Hawkes process | 冲突新闻和价格跳跃的聚集性 |

### 6.3 机器学习与深度时序

| 模型族 | 作用 | 必须搭配的验证 |
| --- | --- | --- |
| XGBoost/LightGBM/CatBoost | 非线性与交互、强表格基线 | 时间滚动验证、SHAP 稳定性 |
| Random Forest/Extra Trees | 非参数预测、变量关系探索 | blocked cross-validation |
| TCN/N-BEATS/N-HiTS | 多步序列预测 | 多预测期限误差与消融 |
| Temporal Fusion Transformer | 多变量、多期限、静态与时变特征 | attention/feature gate 稳定性 |
| Graph Neural Network | 多市场与航运网络联动 | 与无图结构模型的消融比较 |
| Mixture-of-Experts | 为正常、战争、危机状态训练专家 | gating 是否提前泄露 regime |

TFT 的原始设计面向带静态变量、已知未来输入和历史外生变量的多期限预测，并包含变量选择与可解释注意力机制，可作为本题多源预测的结构参考：[Lim et al. (2021)](https://doi.org/10.1016/j.ijforecast.2021.03.012)。

### 6.4 概率预测与不确定性

- Quantile regression、quantile boosting、DeepAR：直接预测分位数。
- Bayesian posterior predictive distribution：分解参数与观测不确定性。
- Adaptive conformal prediction：在分布漂移下动态校准区间。
- Extreme Value Theory：估计战争期尾部涨幅和极端波动概率。
- Scenario mixture：将停火、持续冲突、航道中断、供应替代作为混合情景。

Adaptive Conformal Inference 可作为任何点预测或分位数模型外层的在线区间校准器，其设计目标是在未知分布随时间变化时调整覆盖率：[Gibbs & Candès (2021)](https://proceedings.neurips.cc/paper/2021/hash/0d441de75945e5acbc865406fc9a2559-Abstract.html)。

## 7. 第一问的战争识别路线

### 7.1 双反事实设计

定义潜在油价 `P(I,D)`，其中 `I` 表示战争信息/风险状态，`D` 表示物理供应或运输中断状态。观测状态为 `P(1,1)`，并构造：

1. `P(0,0)`：没有战争信息，也没有物理中断。
2. `P(1,0)`：存在战争信息和风险溢价，但没有物理中断。

于是：

```text
信息/风险溢价效应 = P(1,0) - P(0,0)

物理中断效应（给定战争信息） = P(1,1) - P(1,0)

总战争相关效应 = P(1,1) - P(0,0)
                 = 信息效应 + 物理中断效应
```

若还能构造 `P(0,1)`，可进一步使用四状态的 factorial decomposition 或 Shapley decomposition，把信息、物理中断及二者交互按对称规则分配。这个分解比单一战争 dummy 更能回答“战争如何造成重大影响”，但每个潜在状态的可识别性必须分别论证。

### 7.2 Narrative sign-restricted SVAR

把已核验事件叙事转化为冲击符号或历史分解限制。例如：

- 已确认设施受损日：供应冲击不应为正。
- 航运风险突然上升但产量未变：预防性需求/风险冲击占主导。
- 停火消息日：战争风险冲击应下降。

Narrative sign restrictions 可以用历史事件叙事约束结构冲击或历史分解，并已被用于油市识别；具体限制仍须由本项目事件证据预先定义：[Antolín-Díaz & Rubio-Ramírez (2018)](https://doi.org/10.1257/aer.20161852)。

### 7.3 多模型反事实集成

并行估计：

- Event study / interrupted time series
- BSTS / CausalImpact
- Local Projection
- Synthetic control based on other commodities or assets
- Narrative SVAR historical decomposition
- ML forecast residual counterfactual

不把某一个模型当成绝对真值，而对各方法的战争影响估计进行：

- median ensemble
- Bayesian model averaging
- specification curve
- partial identification interval

### 7.4 冲击“指纹识别”

为历史冲击建立特征指纹：

```text
价格方向
期限结构变化
库存反应
产量反应
运价反应
美元反应
波动率反应
持续时间
```

用 metric learning、dynamic time warping 或聚类，比较 2026 冲击与海湾战争、俄乌冲突、OPEC 减产、疫情复苏等历史片段的相似性。该结果是类比与机制证据，不单独构成因果识别。

## 8. 第一问的原创组合候选

### 组合 Q1-A：事件图谱—状态转换—叙事 SVAR

事件图谱生成连续战争强度，Markov-switching 判断市场状态，Narrative SVAR 分解供应、需求和风险冲击。

### 组合 Q1-B：TFT—Conformal—BSTS

TFT 提供多期限分位数预测，Adaptive Conformal 校准战争期区间，BSTS 构造无战争路径。

### 组合 Q1-C：航运网络 GNN—物理供应反事实

用港口、海峡、航线和来源国构图，GNN 预测运输约束，再与纯新闻风险模型比较，以分离物理通道和信息通道。

### 组合 Q1-D：结构模型与 ML 残差正交化

先由结构基本面模型预测正常油价，再让 ML 只学习剩余的非线性部分；随后用事件冲击识别解释正交化残差，减少把可解释基本面重复归因给战争的风险。

### 组合 Q1-E：预测市场期限结构—隐状态—油市价格发现

从同一战争事件的多期限 Polymarket 合约恢复升级、停火和恢复通航的概率期限结构，经流动性校准后进入 state-space 模型；再与 Brent/WTI 期货、波动率和航运数据做 lead–lag、Hawkes 或 price-discovery 分析，判断“战争信息—风险溢价—物理供应”三类信号的先后顺序。

## 9. 第一问的验证与证伪

- 所有模型在完全相同的滚动窗口比较。
- 同时评价 MAE、RMSE、CRPS、pinball loss、区间覆盖率和方向准确率。
- 对事件日期做假事件 placebo。
- 对其他大宗商品和与中东供给关联较弱的资产做负对照。
- 删除某类新闻来源后重复事件强度构造。
- 更换 Brent、WTI、Dubai/Oman 和中国 SC 原油期货。
- 分别报告 total effect 与控制中介后的 direct effect，避免把 post-treatment control 混入总效应模型。
- 对 Polymarket 特征报告 Brier/log score、reliability diagram、spread/volume/depth 分层结果以及去除最大交易钱包后的敏感性。
- 比较 last trade、midquote、流动性加权概率和校准概率，防止把微观结构噪声写成信息优势。
- 做“只使用当时已经创建且规则已经公布的合约”的 point-in-time 回测，禁止用后来创建的市场重构早期风险。
- 将 Polymarket 变量从总效应模型中移除、再作为中介加入，明确展示它吸收的是信息通道而非物理中断本身。
- VECM/TVECM 只有在协整秩、结构突变和参数稳定性检验支持时进入主模型，否则降级为 distributed-lag 或 state-space 方案。
- 如果无战争反事实在战前无法稳定拟合，则不得给出强因果结论。

# 第二问：油价冲击如何影响中国经济增长

## 10. 第二问应回答的五个层次

1. 总量：实际 GDP 和工业增加值变化多少。
2. 价格：进口价格、PPI、CPI 如何传导。
3. 支出：消费、投资、出口和财政如何响应。
4. 行业与地区：谁受到的冲击最大。
5. 福利：企业利润、居民实际收入和不同群体负担如何变化。

## 11. 第二问的多频宏观系统

### 11.1 双时钟设计

建立两套同步系统：

- **快速时钟**：日度/周度油价、汇率、金融市场和新闻，用于 nowcast。
- **慢速时钟**：月度工业、价格和贸易，季度 GDP，用于正式宏观传导。

Mixed-Frequency VAR 可以在状态空间中联合月度和季度变量，并用贝叶斯方法估计：[Schorfheide & Song (2015)](https://doi.org/10.1080/07350015.2014.954707)。

可进一步加入：

- MF-BVAR
- MIDAS / U-MIDAS
- Dynamic Factor Model
- state-space nowcasting
- temporal aggregation consistency constraints

要求月度预测聚合后与季度 GDP 口径一致，形成跨频率一致性校准。

## 12. 第二问的结构识别与动态响应

### 12.1 冲击分类

第二问至少同时估计：

- 油供给冲击；
- 全球需求冲击；
- 石油特定需求/预防性需求冲击；
- 战争信息冲击；
- 油价不确定性冲击。

同样的油价上涨在不同冲击类型下可能对应不同的中国增长方向，因此不能直接使用单一油价涨幅系数。

### 12.2 主计量模型族

| 目标 | 方法 |
| --- | --- |
| 结构冲击 | SVAR、sign-restricted SVAR、proxy-SVAR、Narrative SVAR |
| 动态响应 | Local Projection、BVAR、TVP-VAR |
| 长期关系与偏离修复 | VECM、time-varying VECM、threshold VECM |
| 高维控制 | FAVAR、factor-augmented LP、DML |
| 非对称 | NARDL、threshold VAR、smooth-transition LP |
| 尾部和状态依赖 | quantile LP、state-dependent LP、Markov-switching VAR |
| 时变传导 | TVP-VAR、rolling LP、time-varying parameter regression |

Local Projection 的方法锚点见 [Jordà (2005)](https://doi.org/10.1257/0002828053828518)。若使用高维控制变量，Double/Debiased Machine Learning 可通过正交得分和 cross-fitting 降低正则化偏误，但时间依赖条件需要专门处理，不能直接随机切分：[Chernozhukov et al. (2018)](https://doi.org/10.1111/ectj.12097)。

## 13. 动态传导网络

### 13.1 从线性链条升级为网络

构造多层网络：

```text
国际油价层
→ 进口来源与运输层
→ 炼化和能源投入层
→ 行业投入产出层
→ 省际贸易层
→ 居民消费层
→ 宏观政策层
```

节点可以是行业、省份、居民组或宏观变量；边权来自投入产出系数、贸易流、能源消费或估计的动态传导系数。

### 13.2 动态投入产出价格模型

把静态 Leontief 价格模型扩展为：

```text
p_t = A_t' p_t + B_t oilshock_t + adjustment_cost_t
```

允许：

- 投入系数随时间变化；
- 企业库存延迟成本传导；
- 国内调价机制产生非线性；
- 进口替代改变行业暴露；
- 价格黏性导致不同传导速度。

### 13.3 省际—行业异质性

可以构造三维张量：

```text
Impact[shock_type, horizon, province, industry]
```

再使用：

- tensor factorization
- spatial econometrics
- network propagation
- hierarchical Bayesian model
- causal forest / generalized random forest

识别哪些地区和行业对战争型油价冲击最敏感。Generalized Random Forest 可作为异质性估计的方法参考：[Athey, Tibshirani, & Wager (2019)](https://doi.org/10.1214/18-AOS1709)。

## 14. 传导机制的因果中介分解

把总效应拆为若干动态路径：

```text
Oil shock
├─→ import cost → PPI → CPI → real income → consumption → GDP
├─→ production cost → profit → investment → output
├─→ trade balance → exchange rate → imported inflation
├─→ uncertainty → precautionary saving → consumption
└─→ policy response → interest/credit/fiscal support → GDP
```

可使用：

- sequential mediation
- interventional indirect effects
- causal mediation with DML
- dynamic path analysis
- structural equation model
- Shapley path decomposition

这里应分别报告 total effect、direct effect 和 path-specific effect。控制中介变量后的系数不是总效应。

## 15. 机制模型与数字经济体

### 15.1 Dynamic IO / MRIO

用于回答：

- 哪些行业直接耗油最多；
- 哪些行业通过供应链间接暴露；
- 国内替代和进口替代能缓冲多少；
- 产业链中心节点是否放大冲击。

### 15.2 CGE

用于同时处理：

- 要素替代；
- 居民消费；
- 政府税收与补贴；
- 进口和出口；
- 行业产出与价格；
- 福利变化。

### 15.3 DSGE

可以显式加入：

- 能源作为生产要素；
- 国内成品油价格平滑规则；
- 价格黏性；
- 货币政策和汇率规则；
- 战略储备；
- 能源替代资本；
- 风险溢价冲击。

### 15.4 Agent-Based Model

把炼厂、运输企业、能源密集型企业、家庭、银行和政府设为异质主体，模拟：

- 企业库存与套期保值；
- 家庭消费调整；
- 信贷约束；
- 政策预期；
- 非线性级联和阈值。

ABM 的结果应与宏观计量和投入产出结果对照，避免仅凭行为规则产生不可验证的故事。

### 15.5 Stock-Flow Consistent 宏观金融模型

建立家庭、企业、银行、政府和国外部门的资产负债表与资金流量账户，确保每一笔支出对应另一部门的收入或负债变化。油价冲击可通过：

- 进口账单和经常账户；
- 企业现金流、利润和债务偿付；
- 居民实际收入和储蓄；
- 银行信贷质量；
- 财政补贴和政府负债

进入模型。SFC 特别适合说明“短期补贴稳定产出，但财政成本和企业/银行资产负债表风险被推迟到未来”的跨期权衡，补足 VAR 只描述动态相关、IO 只描述实体投入链的不足。

### 15.6 投资等待与 Real Options

油价水平与波动上升可能同时提高企业的生产成本和投资等待价值。可对行业 `j` 建立：

```text
Invest when:
expected_project_value_(j,t) - sunk_cost_j
> option_value_of_waiting_(j,t)
```

由油价 jump/volatility、行业能源强度、融资约束和可替代能源资本共同决定等待阈值。该模块可解释为什么油价冲击即使尚未大幅减少当期产量，也会通过推迟固定资产投资影响中期增长。

### 15.7 能源系统—宏观经济联结

将交通、电力、炼化或 TIMES/MARKAL 式能源系统与 CGE/DSGE 软链接或硬链接，使油价冲击内生改变：

- 新能源汽车渗透和燃油需求；
- 铁路、公路、航空之间的运输替代；
- 煤、气、电和油之间的工业能源替代；
- 能效投资和定向技术进步；
- 能源资本形成及其对长期增长的反馈。

软链接可迭代交换能源价格、需求和投资路径；硬链接则在同一优化系统中求解。两种方式都必须报告收敛准则和能源平衡误差。

## 16. 第二问的原创组合候选

### 组合 Q2-A：结构冲击—MF-BVAR—动态投入产出

用第一问冲击进入 MF-BVAR 得到宏观响应，再把进口成本和 PPI 响应输入动态 IO，形成“宏观响应 + 行业机制”闭环。

### 组合 Q2-B：State-dependent LP—因果中介—居民福利

分别估计低增长/高增长、高通胀/低通胀状态下的响应，再把实际收入、消费和就业作为动态中介，得到分群体福利影响。

### 组合 Q2-C：宏观—行业—省际冲击张量

融合 BVAR posterior、MRIO 和省际贸易网络，输出 `shock × horizon × industry × province` 的四维响应张量。

### 组合 Q2-D：计量模型与结构数字孪生的 Bayesian melding

用 BVAR/LP 的脉冲响应约束 CGE/DSGE 参数，使结构模拟同时符合经济理论和历史动态；将参数不确定性传递到政策实验。

### 组合 Q2-E：油价不确定性—Real Options—SFC 资产负债表

第一问输出油价跳跃和波动分布，Real Options 估计各行业投资等待阈值，SFC 再把投资推迟、现金流恶化、信贷收缩和财政缓冲连接为跨期增长路径。

### 组合 Q2-F：动态 IO—能源系统—内生技术替代

动态 IO 识别短期供应链成本级联，能源系统模型计算油、电、气及交通技术的替代边界，CGE/DSGE 将替代投资、资本积累和居民福利反馈到中长期增长。

## 17. 第二问的验证与证伪

- 更换冲击识别方案，比较 IRF 是否稳定。
- 同时估计战争型、供给型和全球需求型冲击。
- 对疫情、金融危机、俄乌冲突做分样本和结构突变检验。
- 检验季度 GDP 与月度代理聚合的一致性。
- 对 Local Projection 的 horizon、滞后阶数和标准误方案做 specification curve。
- 对 IO/CGE/DSGE 参数做全局敏感性和 Sobol 分解。
- 对 SFC 逐期核对部门预算约束、存量—流量一致性和总资产等于总负债。
- 对 Real Options 比较“价格水平效应”与“波动/等待效应”，并用行业投资数据检验阈值排序。
- 对能源—宏观联结报告能量守恒、迭代收敛、替代弹性和技术成本的全局敏感性。
- 对中介分析检查 post-treatment confounding。
- 对行业和省际异质性做多重检验校正。
- 如果不同模型只在符号上相同但量级差异巨大，应把模型不确定性作为结果，而不是平均后掩盖。

# 第三问：中国政策缓冲机制与跨国比较

## 18. 先重新定义“应对得更好”

不建议直接构造一个任意加权总分。应将“更好”定义成多目标韧性前沿：

```text
最小化：
  国内能源价格涨幅
  CPI/PPI 冲击
  产出与就业损失
  财政成本
  外汇与金融风险
  能源短缺概率
  碳排放反弹

最大化：
  恢复速度
  供应可靠性
  政策可持续性
  分配公平
```

中国可能在部分维度更好、部分维度代价更高。因此应先画 Pareto frontier，再讨论综合判断。

可增加三类韧性度量：

- **Resistance**：冲击峰值有多小。
- **Recovery**：恢复速度有多快。
- **Adaptation**：冲击后结构是否降低下一次暴露。

## 19. 暴露调整后的跨国比较

### 19.1 韧性效率而非原始结果

使用：

- Data Envelopment Analysis
- Stochastic Frontier Analysis
- multi-objective efficiency frontier

输入可包括净进口依赖、油强度、产业结构和冲击规模；输出包括通胀、产出、供应稳定和财政成本。这样比较的是“在既定暴露下缓冲得多好”，而不是只比较 GDP 增速。

### 19.2 Hierarchical panel Local Projection

建立：

```text
ΔY_(i,t+h)
= country effect
+ time effect
+ OilShock_t
+ OilShock_t × Policy_(i,t)
+ OilShock_t × StructuralExposure_(i,t)
+ controls
```

使用 hierarchical Bayesian partial pooling，使国家响应既共享信息又保持异质性。政策系数可随冲击类型和 horizon 改变。

## 20. 跨国反事实工具箱

| 方法 | 适合回答 |
| --- | --- |
| Synthetic Control | 中国若按加权对照国路径运行会怎样 |
| Augmented SCM | 处理前拟合不完美时的偏差修正 |
| Matrix Completion | 多国家、多时期和潜在因子下的反事实 |
| Synthetic Difference-in-Differences | 同时结合单位和时间权重 |
| Generalized Synthetic Control | 交互固定效应与时变潜在因子 |
| CausalImpact/BSTS | 单项政策的时间序列反事实 |
| DID/event study | 有明确时点且前趋势可信的政策 |
| DML/causal forest | 高维政策条件和异质缓冲效应 |

Synthetic Difference-in-Differences 将 DID 与 Synthetic Control 的单位和时间加权思想结合，可作为传统两种估计的交叉验证：[Arkhangelsky et al. (2021)](https://doi.org/10.1257/aer.20190159)。高维政策和结构变量较多时，DML 的正交化与 cross-fitting 可减少 nuisance model 的正则化偏误：[Chernozhukov et al. (2018)](https://doi.org/10.1111/ectj.12097)。

## 21. 政策包拆解

将政策分成可开关模块：

| 政策模块 | 状态变量或控制量 |
| --- | --- |

| 成品油定价 | 调价周期、传导率、上限/下限、平滑系数 |

### 21.1 把成品油定价规则变成可估计的政策函数

团队讨论提出用 TVECM 表示国内成品油价格的非线性传导，这一想法适合保留，但阈值含义必须按正式政策文本编码。国家发展改革委公布的规则包括：

- 国际市场原油价格低于 40 美元/桶时，国内成品油价格不再下调，未调金额进入风险准备金；
- 40–80 美元/桶按正常加工利润率计算；
- 高于 80 美元/桶开始扣减加工利润率，直至零加工利润；
- 高于 130 美元/桶时原则上不提或少提，并以财税政策保障生产供应；
- 常规情况下每 10 个工作日调整一次，幅度低于每吨 50 元时累积至下一周期。

规则来源见国家发展改革委的[《石油价格管理办法》及 2016 年完善通知](https://www.ndrc.gov.cn/xxgk/zcfb/tz/201601/t20160113_963566_ext.html)。因此，80 美元并不是简单的“零售价格封顶点”，而是加工利润计算方式开始变化的节点；不能把讨论稿中的分段表达直接当成真实价格方程。

该文件定义的是 2016 年起的政策版本。实证时仍须按日期建立政策版本表，并用每次调价公告和后续修订核对样本期适用规则；不能因 2026 年仍有“按机制调整”的公告，就未经检查地假定所有参数从未改变。

可依次采用：

1. **制度仿真**：用真实的 10 工作日参考油价和累积规则重建政策建议价；
2. **Threshold VECM / smooth-transition model**：估计国际原油与国内汽柴油的长期关系、误差修正速度和不同区间的传导率；
3. **Threshold Local Projection**：比较同一外部冲击在价格区间、调价窗口和特殊调控状态下的宏观响应；
4. **Regression kink/discontinuity**：仅在阈值附近观测充分、政策规则未同期改变、操纵和预期效应可排除时使用；
5. **政策移除反事实**：把估计的政策函数替换为完全市场化、他国传导率或不同调价周期，输入第二问的宏观系统。

最直接的政策缓冲量不是“国内价格比国际价格低多少”，而是：

```text
pass_through_gap_t =
  counterfactual_market_price_change_t
  - observed_domestic_price_change_t
```

再把该缺口分为调价周期、40/80/130 区间、暂停/延迟调价、税费和补贴贡献。若使用实际国内价格构造政策强度，应注意它本身是油价冲击后的结果，跨国面板中不能无条件当作前定解释变量。

## 22. 政策组合的创新归因

### 22.1 政策 Shapley 分解

将每个政策模块视为合作博弈参与者：

```text
v(S) = 采用政策集合 S 时减少的宏观损失
```

用 Shapley value 分解：

- 每项政策的平均边际贡献；
- 政策之间的协同或替代；
- 不同冲击类型下贡献是否变化。

Shapley 结果是结构模型或反事实模型的归因，不自动等于现实因果效应。

### 22.2 政策互换棋盘

建立国家—政策互换矩阵：

```text
Outcome(country economy i, policy package j, shock scenario k)
```

例如：

- 中国经济 + 日本政策；
- 中国经济 + 韩国政策；
- 日本经济 + 中国政策；
- 中国经济 + 无价格平滑；
- 中国经济 + 更高进口集中度。

这样可以分离“经济结构好”与“政策包好”，避免把中国经济规模和产业结构误认成政策效果。

### 22.3 结构—政策—外部因素三重 Oaxaca/Shapley 分解

将中国与对照国表现差异拆为：

```text
Difference
= structural endowment
+ active policy
+ external environment
+ interaction
+ unexplained
```

可分别用 Oaxaca-Blinder、Shapley decomposition 或结构反事实实现。

## 23. 政策数字孪生与最优控制

### 23.1 Model Predictive Control

将第一问预测分布与第二问宏观状态模型作为动态系统：

```text
x_(t+1) = F(x_t, oilshock_t, policy_t)
```

政策控制量：

```text
u_t = [
  reserve_release,
  price_smoothing,
  subsidy,
  tax_adjustment,
  exchange_rate_support,
  import_reallocation
]
```

每期根据最新油价预测重新优化未来政策路径。

### 23.2 鲁棒控制与分布鲁棒优化

不假设某个预测模型一定正确，而在多个油价模型、冲击情景和参数集合上求：

```text
min_policy max_model ExpectedLoss
```

或使用 distributionally robust optimization，使政策在概率分布错设时仍保持可接受表现。

### 23.3 多目标优化

目标函数可包括：

```text
Loss
= w1 × GDP loss
+ w2 × inflation
+ w3 × fiscal cost
+ w4 × shortage risk
+ w5 × inequality
+ w6 × carbon impact
```

不要只给一组主观权重，应输出 Pareto frontier，并做权重、风险厌恶和情景概率敏感性。

### 23.4 储备的 Real Options 价值

把战略储备视为一项可等待、可分期执行的期权：

- 立即释放的缓冲收益；
- 未来更严重冲击下失去选择权的成本；
- 补库成本；
- 信息等待价值。

用 real options 或 stochastic dynamic programming 决定释放阈值，而不是只比较“释放/不释放”。

可将其写成近似的 Bellman/HJB 问题：

```text
V(stock_t, oil_state_t, macro_state_t)
= min_release {
    current_macro_loss
  + release_cost
  + expected_future_value
}
```

约束必须包括库存不可为负、最大释放/补库速度、油品结构与库点可达性。第一问的情景概率或 Polymarket 校准概率可以更新 `oil_state_t` 的转移分布，但不应成为唯一情景来源。

### 23.5 进口网络的 CVaR 优化

对来源国和航线配置进行多目标优化：

```text
min expected_cost
+ λ1 × CVaR(supply_loss)
+ λ2 × concentration
+ λ3 × transport_emission
```

约束包括炼厂适配、合同、航程、港口能力和地缘政治相关性。结果可以解释进口多元化为什么缓冲冲击，以及多元化的成本。

### 23.6 博弈论与 Multi-Agent Reinforcement Learning 政策实验室

把 OPEC/非 OPEC 生产者、进口国、航运企业、炼厂和储备管理者设为具有不同目标的主体：

- Stackelberg game：产油国先决定产量/价格策略，进口国再选择储备和替代；
- stochastic game：战争状态、航道容量和政策状态共同转移；
- evolutionary game：长期合同、联盟和进口来源选择随收益改变；
- multi-agent reinforcement learning：各国政策代理在相同冲击生成器下学习储备、补贴、调价和进口调整组合。

MARL 的价值是发现传统规则没有枚举到的非线性策略与对手反应，不是产生现实政策因果证据。应把其策略与 MPC、鲁棒控制和历史政策规则放在同一组 out-of-sample 情景中比较，并对 reward 设定、训练随机种子和未见冲击做压力测试。

## 24. 第三问的原创组合候选

### 组合 Q3-A：韧性前沿—Hierarchical LP—SDID

先用多目标前沿判断中国在哪些维度更好，再用层级面板 LP 估计政策交互，最后用 SDID 做政策组合反事实。

### 组合 Q3-B：SCM/Matrix Completion ensemble—政策 Shapley

将 SCM、Augmented SCM、Matrix Completion 和 SDID 的反事实做 ensemble，再在统一宏观损失函数上进行政策 Shapley 分解。

面板因果方法也可以像预测模型一样组合；已有研究提出对不同面板因果估计进行 ensemble：[Athey et al. (2019)](https://doi.org/10.1257/pandp.20191069)。

### 组合 Q3-C：政策互换棋盘—结构反事实

把国家结构和政策规则分离，系统模拟 `经济体 i × 政策包 j × 冲击 k`，得到结构优势、主动政策和外部环境的三重分解。

### 组合 Q3-D：油价概率预测—MPC—鲁棒政策

第一问输出概率情景，第二问提供状态转移，第三问通过 MPC 和鲁棒优化动态选择储备、调价、补贴和进口调整。

### 组合 Q3-E：能源安全—经济增长—碳排放三目标数字孪生

将短期缓冲、长期能源转型和碳目标放入同一 Pareto 前沿，判断某项政策是“真正降低脆弱性”还是“只把当前成本转移到财政或未来”。

### 组合 Q3-F：阈值传导—储备 HJB—对抗式政策实验室

先用 TVECM/threshold LP 估计 40/80/130 美元区间和调价周期下的国内传导，再用 HJB 求储备释放规则，最后让 MARL 产油国/进口国代理生成对抗情景，检验中国政策组合是否只在既有历史路径中有效。

## 25. 第三问的验证与证伪

- 在任何比较前固定“更好”的评价维度。
- 检验不同权重下中国排序是否稳定。
- SCM 报告处理前 RMSPE、donor 权重、placebo、leave-one-out。
- DID/SDID 报告前趋势和 anticipation effect。
- 排除同时受中国冲击溢出的 donor，或显式建模 spillover。
- 政策时点与强度必须来自可核验材料。
- 按官方文本编码成品油规则；分别检验 40、80、130 美元节点、10 工作日窗口和每吨 50 元累积规则，不能只拟合一个方便的分段函数。
- 阈值附近样本稀少时放弃伪精确的断点因果结论，改做结构仿真与部分识别。
- 同时报告政策成本和收益。
- 区分政策 total effect 与某条传导路径的 indirect effect。
- 若同一政策只在某些模型中有效，报告模型依赖性。
- 对 MARL 报告 reward sensitivity、随机种子、策略崩溃率和未见冲击表现，并用历史规则和 MPC 作基线。
- 进行“反向结论”检验：是否存在合理指标下其他国家表现更好。

## 29. 不确定性总账

最终政策结论的区间至少包含：

1. 数据修订和测量误差；
2. 预测误差；
3. 冲击识别不确定性；
4. 宏观响应参数不确定性；
5. 模型选择不确定性；
6. 预测市场的校准、流动性、市场选择和结算规则不确定性；
7. 政策参数和情景概率不确定性。

建议使用 nested bootstrap、posterior simulation 或 Monte Carlo 将各层 draws 串联。不要只在最后一层添加一个标准误。

## 31. Devil's Advocate：最可能击穿论文的十二个问题

| 攻击 | 严重性 | 设计层面的应对 |
| --- | --- | --- |
| 单次战争事件不足以证明因果 | Critical | 多历史事件、叙事限制、负对照、部分识别 |
| 把全球需求型涨价当成战争供给冲击 | Critical | 结构冲击分解和历史分解 |
| 反事实模型使用了战争后的中介变量 | Critical | 明确 total/direct effect，建立 DAG |
| 使用修订后或尚未发布的数据预测历史 | Critical | information vintage 和 release-date matrix |
| 模型很多，最后挑最符合预期的一个 | Critical | 预先注册评价规则、完整 specification curve |
| “中国应对更好”被当成先验事实 | Critical | 多维指标、反向结论检验、Pareto 前沿 |
| 跨国 donor 同时受到中国或战争溢出 | Major | spillover-aware donor 筛选或网络模型 |
| SHAP/attention 被写成因果贡献 | Major | 仅作预测解释，因果结论来自识别模型 |
| CGE/DSGE 给出过度精确的数字 | Major | 参数校准区间、全局敏感性、与计量结果对照 |
| 政策收益没有计算财政与长期成本 | Major | 多目标损失函数和动态成本收益 |
| 把 Polymarket 价格当成真实概率或外生冲击 | Critical | 历史校准、流动性权重、只作预测/中介，禁作未经论证的 IV |
| 后创建合约、事后规则或陈旧成交造成信息泄漏 | Critical | point-in-time 市场集合、规则版本化、midquote/盘口质量检查 |

最强的反对意见是：

> 2026 战争、全球供需、美元、库存和各国政策同时变化，任何漂亮的反事实都可能只是模型假设的产物。

论文必须正面回应：用多方法三角验证、负对照、历史事件、机制数据、部分识别区间和模型不确定性总账，说明哪些结论稳定、哪些只在特定假设下成立。

## 33. 团队讨论的吸收与取舍

`discussion.md` 是高覆盖率的方法头脑风暴，其中大部分经典方法已存在于本指南。为避免方法名堆叠，本次按“是否新增可估计对象、识别逻辑或跨问接口”筛选：

| 讨论想法 | 处理 | 理由或落点 |
| --- | --- | --- |
| VECM/TVECM、latent risk state、Realized GARCH/SVJ | 纳入 | 分别补充长期均衡、隐含风险溢价和高频波动/跳跃 |
| SFC、投资等待 Real Options | 纳入 | 补充宏观金融资产负债表与投资推迟通道 |
| 能源系统—宏观联结、内生技术替代 | 纳入 | 把短期冲击扩展到交通电动化、燃料替代和长期增长 |
| 成品油 40/80/130 美元分段机制 | 校正后纳入 | 按国家发展改革委正式文本重写；80 美元不是简单零售封顶点 |
| HJB 储备优化、博弈论和 MARL | 纳入为实验层 | 用于政策压力测试和发现非线性策略，不充当经验因果证据 |
| ARIMA/GARCH/VAR、ML、分解集成、Hawkes、ABM、AIS/NLP | 不重复增列 | 现有第一至第三问方法链已经覆盖 |
| fractional Brownian、multifractal、Ising-like market | 保留为附录候选 | 可描述长记忆和羊群级联，但对三问的结构解释增量尚不明确；必须先赢过 HAR-RV、SVJ 和 regime baseline |
| 原油期货 limit-order-book 全量建模 | 条件纳入 | 若能取得可靠 L2 历史数据，可做高频价格发现；若只有免费收盘数据，不应伪造盘口分析。Polymarket 公共 WebSocket 可从当前开始前瞻采集 |
| 讨论稿中的论文题名、引用次数和经验结论 | 不自动采纳 | 只有经 DOI、出版社或机构官网核验后才能进入正式证据表 |

这一取舍不限制后续实验。任何“保留为候选”的方法，只要能定义清楚它回答的子问题、信息集、基线和证伪标准，仍可进入模型注册表。

## 34. 推荐的论文叙事

论文不必按模型名称组织，而应按问题证据组织：

1. **战争改变了什么？**  
   用状态、预测分布和双反事实回答。
2. **为何可以认为变化与战争有关？**  
   用结构冲击、事件证据、负对照和多方法一致性回答。
3. **这些冲击如何进入中国经济？**  
   用宏观响应、动态中介和产业网络回答。
4. **中国究竟在哪些维度更有韧性？**  
   用暴露调整和 Pareto 前沿回答。
5. **韧性来自结构还是政策？**  
   用跨国反事实、政策互换和 Shapley 分解回答。
6. **未来应该怎样响应？**  
   用政策数字孪生、鲁棒控制和多目标优化回答。
