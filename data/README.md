# 数据目录

本项目只使用免费公开数据，主样本观测截止日统一为 2026-06-30。

该日期是最后一个完整自然月和季度末。不同来源存在发布滞后时，使用观测日期不晚于 2026-06-30 的最新可得值，并在登记表中保留每个序列的真实末期。下载日期和观测截止日必须分开记录。

## 目录

- `event_timeline.csv`：已核验的战争、航运中断、国内政策和缓和阶段定义。
- `DATA_DICTIONARY.csv`：字段级变量定义、转换、发布日期、截止规则和回退变量。
- `SOURCE_REGISTRY.csv`：官方来源、精确接口、访问状态、许可和模型放行条件。
- `raw/`：从官方来源获得的原始文件，只读保存，不手工修改。
- `processed/`：由 `code/` 中脚本生成的清洗、聚合和对齐数据。

## 数据审计状态

完整结论见 `reports/DATA_SOURCE_AUDIT.md`。状态口径如下：

- `PASS`：官方免费入口和关键字段已核验，可以编写下载脚本。
- `CONDITIONAL`：仍需免费密钥、人工导出、反爬处理、口径拼接或发布日期边界检查。
- `FAIL_FOR_MAIN`：不进入主线，按预定回退处理。
- `DERIVED`：由已核验变量在处理脚本中生成。

当前最重要的条件项是国家统计局月度数据的稳定导出、日本燃油历史 Excel 的 403、韩国 Opinet 免费密钥，以及 EIA STEO 历史估计与预测边界。中国原油进口单位价值只作验证；主传导变量先使用 Brent 月均价乘人民币兑美元汇率。

## B 档数据层

- 月度主线：Brent、供需、库存、美元、GPR、中国宏观和跨国结果变量。
- 日度补充：Brent/WTI、金融控制和 `event_timeline.csv`，只用于 Q1。
- 季度验证：实际 GDP，不插值为月度。
- 发布日期矩阵：每个特征记录观测期和最早可用日期，预测时只使用当时已发布信息。

## 强制检查

- 原始文件校验值
- 首末日期和观测数量
- 缺失、重复和异常值
- 频率、币种、价格口径和季调状态
- 数据发布滞后及修订版本
- 来源许可是否允许提交到 GitHub
- `SOURCE_REGISTRY.csv` 中的接口状态与实际下载响应是否一致
- API 密钥只能由环境变量读取，禁止写入仓库
