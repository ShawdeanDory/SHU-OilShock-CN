# 数据目录

本项目只使用免费公开数据，但不再用一个“截止日”混合不同时间概念：

- 市场预测信息截止日：2026-06-30；Q1/Q4实时预测只能使用当日已经发布的信息。
- 统计观测期末：月度序列可覆盖至2026-06，季度序列可覆盖至2026Q2。
- 数据发布日期：逐序列记录；晚于2026-06-30发布的2026-06/2026Q2数据只用于事后传导解释。
- 下载/版本日期：记录实际抓取或人工导出日期、快照链接和原始哈希。

## 目录

- `event_timeline.csv`：已核验的战争、航运中断、国内政策和缓和阶段定义。
- `DATA_DICTIONARY.csv`：字段级变量定义、转换、发布日期、截止规则和回退变量。
- `SOURCE_REGISTRY.csv`：官方来源、精确接口、访问状态、许可和模型放行条件。
- `raw/`：从官方来源获得的原始文件，只读保存，不手工修改。
- `processed/`：由 `code/` 中脚本生成的清洗、聚合和对齐数据。

当前已经生成 P0 市场日度/月度表、国家统计局工业增加值与 PPI、OECD CPI 与工业生产、德国、日本和韩国燃油价格、中国政策事件、STEO 条件数据、来源快照清单和发布日期规则矩阵。完整质量结论见 `reports/DATA_QUALITY_REPORT.md`。

## 数据审计状态

完整结论见 `reports/DATA_SOURCE_AUDIT.md`。状态口径如下：

- `PASS`：官方免费入口和关键字段已核验，可以编写下载脚本。
- `CONDITIONAL`：仍需免费密钥、人工导出、反爬处理、口径拼接或发布日期边界检查。
- `FAIL_FOR_MAIN`：不进入主线，按预定回退处理。
- `DERIVED`：由已核验变量在处理脚本中生成。

国家统计局工业增加值和PPI的2010-01至2026-06人工导出已经完成，并由`code/data_processing/import_nbs_manual.py`校验原始哈希、指标、覆盖区间和官方缺失口径。剩余条件项是海关统计平台的登录限制，以及EIA STEO历史估计与预测边界；两者均已按回退规则退出主规格。韩国燃油价已改用无需账号的KOSIS官方月表；德国、日本、韩国燃油价均已进入处理层。中国2013—2025燃油历史路径是由公开调价信息重构的“受管制汽油调价指数代理”，不是固定产品、固定地区的完整官方逐月零售限价，故退出正式跨国价格水平主排名；2026政策差额按对应公告单独核验。中国原油进口单位价值只作验证；主传导变量使用Brent月均价乘人民币兑美元汇率。

`country_policy_buffers_annual.csv`当前仍是待审计规则代理，只保留作数据缺口说明，不进入正式缓冲交互回归。恢复定量结果前必须为每个国家—年份补齐原始值、计算公式、官方URL/表号、下载日期和文件哈希。

## B 档数据层

- 月度主线：Brent、供需、库存、美元、GPR、中国宏观和跨国结果变量。
- 日度补充：Brent/WTI、金融控制和 `event_timeline.csv`，只用于 Q1。
- 季度验证：实际 GDP，不插值为月度。
- 发布日期矩阵：每个特征记录观测期和最早可用日期，预测时只使用当时已发布信息。

## 强制检查

- 原始文件校验值
- 首末日期和观测数量
- 缺失、重复和异常值
- 频率、币种、价格口径和季调状态
- 数据发布滞后及修订版本
- 来源许可是否允许提交到 GitHub
- `SOURCE_REGISTRY.csv` 中的接口状态与实际下载响应是否一致
- API 密钥只能由环境变量读取，禁止写入仓库
