# 原始数据

只存放从免费公开来源获得的原始文件。

- 不允许手工修改。
- 文件名包含来源、指标、频率和下载日期。
- 大文件或不可再分发的数据只保留下载脚本、校验值和来源说明。
- `source_manifest.csv` / `.json`：下载状态、精确 URL、响应元数据、文件大小和 SHA-256。
- `_meta/`：每份成功快照的独立元数据。

人工下载的文件放入 `manual/`，保留官方下载文件名，不要打开后另存或修改内容。

KOSIS 表 `TX_31802_A000` 不需要账号，但交互式表格不提供稳定的免密文件 URL。项目将 2026-07-30 通过浏览器读取并结构化的 2010-01 至 2026-06 普通汽油月均价保存为版本化 CSV；下载器把它当作 `local_snapshot` 校验，禁止用 `--refresh` 覆盖原文件。
